# 🍽️ Old Town Restaurant

A responsive, bilingual digital restaurant menu built with HTML, CSS, and vanilla JavaScript.

Old Town Restaurant provides a simple and elegant browsing experience, allowing visitors to explore food and drinks in both Arabic and English.

## ✨ Features

- **Bilingual Support:** Arabic and English with RTL/LTR layouts.
- **Dynamic Menu:** Menu items are generated using JavaScript.
- **Five Menu Categories:** Specials, Starters, Main Dishes, Desserts, and Drinks.
- **25 Menu Items:** Five products in each category.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.
- **Performance Improvements:** Lazy-loaded images and optimized image requests.
- **Smooth Navigation:** Easy navigation between menu sections.
- **Interactive Product Cards:** Click to highlight a menu item.
- **Contact Section:** Quick access to phone, WhatsApp, Instagram, and Google Maps.

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Abdallahqabbani/restaurant-menu-template-03-Old-Town-.git
```

2. Open the project folder.
3. Launch `index.html` in your browser.
4. Switch between Arabic and English using the language button.

No additional dependencies or installation are required.

## ⚙️ Customization

Menu items are managed inside the `menuItems` array in `script.js`.

You can easily update product names, descriptions, prices, images, and categories without editing the HTML product cards.
